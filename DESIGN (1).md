## Brand & Style

This design system embodies an authoritative, refined enterprise HR and payroll management aesthetic. Designed for global enterprise leaders, HR executives, and financial controllers, the emotional baseline is unyielding precision, institutional trust, and sovereign calm.

The visual language follows an **Executive Minimalist** philosophy tailored for high-density enterprise software. It dismisses fleeting decorative trends, excessive neon accents, and loud gradients in favor of structural clarity, impeccable typographic cadence, and restrained chromatic balance. By contrasting deep imperial aubergines with steadfast ocean teals against immaculate neutral surfaces, the interface balances high-stakes fiduciary rigor with modern digital elegance. Every metric, audit trail, and payroll cycle inspires total operational confidence.

## Colors

The palette operates on a strict functional stratification between institutional authority (the Purple axis) and analytical certitude (the Ocean Teal axis).

### Role Assignments & Token Stratification
- **Primary Imperial Purple (`#3B123F`):** Anchors main navigational structures, top-tier global CTAs, active system states, and critical ledger validations.
- **Secondary Ocean Teal (`#005166`):** Drives operational actions, analytics charts, progress trackers, interactive table actions, and secondary workflows.
- **Deep Ocean Teal (`#064252`):** Reserved for high-density data visualizations, active data filters, and key analytical summaries requiring stark contrast.
- **Secondary Purple (`#542052`):** Utilized for tertiary interactive components, hover fills on primary elements, and nested parent navigations.
- **Surface Backgrounds:**
  - Base Surface (`#FFFFFF`): Main canvas for cards, modal dialogs, and expanded drawer panels.
  - Neutral Background (`#F7FAFA`): Structural canvas base, master viewports, and outer application frame.
  - Light Teal Tint (`#EEF7F7`): Highlighting positive adjustments, active teal selection rows, and analytical card highlights.
  - Light Purple Tint (`#F6F0F7`): Active primary navigation nodes, selected executive profile highlights, and audit pill backgrounds.
- **Structural Lines & Borders (`#E5EAEA`):** Uniform hairline delimiters for all enterprise cards, tables, inputs, and section boundaries.
- **Typography Colors:**
  - Primary Slate Black (`#241C24`): Headlines, numerical ledgers, input text, and high-emphasis data rows.
  - Secondary Teal Slate (`#49636A`): Metadata tags, input labels, table column headers, helper notes, and breadcrumbs.

## Typography

Typography centers on **Plus Jakarta Sans**, chosen for its geometric precision, contemporary sophistication, and crisp legibility within numeric layouts.

### Implementation Guidelines
- **Tabular Figures:** Always apply OpenType tabular figure styling (`tnum`) across all monetary tables, salary grids, timestamp logs, and KPI counters to guarantee vertical alignment.
- **Form Labels:** Form input labels enforce `label-md` using `#49636A`, paired with tight vertical proximity (6px) to their parent input field.
- **Hierarchy Rules:** Large display sizes are reserved solely for high-level payroll sum reconciliations and workspace headers. Primary body copy across data grids, tooltips, and lists must default strictly to `body-md` (`14px`) to preserve high enterprise information density without crowding.

## Layout & Spacing

The system follows an 8-point structural baseline with a supplemental 4-point micro-scale for compact form layouts and table cell padding.

### Layout Model
- **Desktop (1200px+):** 12-column responsive fluid grid with `1.5rem` (24px) gutters, bounded by fixed navigation rail/sidebar (260px expanded, 72px condensed). Content layout maintains balanced horizontal margins of `2rem` (32px).
- **Tablet (768px – 1199px):** 8-column layout with `1rem` (16px) gutters, sliding drawer navigation, and `1.5rem` outer margins. Data tables enable horizontal scrolling with fixed column anchors.
- **Mobile (Below 768px):** 4-column layout with `1rem` margins and gutters. Enterprise cards unstack into single-column vertical flows; multi-stat KPI ribbons collapse into swipeable carousels.

### Layout Rhythm
- Inner card padding strictly enforces `1.25rem` (20px) to `1.5rem` (24px).
- Compact tables utilize a condensed row height of `44px` (`space-sm` vertical cell padding), while standard analytical tables use `56px` row heights.

## Elevation & Depth

Visual hierarchy rejects exaggerated, dark drop shadows. Instead, it relies on tonal layering, 1px structural borders, and diffuse, tinted micro-shadows that keep the interface grounded.

### Surface Tiers
- **Tier 0 (Application Base):** `#F7FAFA`. Foundational backdrop for the entire viewport.
- **Tier 1 (Cards & Data Sections):** `#FFFFFF`, bounded by a continuous `1px solid #E5EAEA` border. Elevation is augmented with an ultra-soft diffuse shadow: `0 1px 3px rgba(36, 28, 36, 0.03), 0 4px 12px rgba(6, 66, 82, 0.02)`.
- **Tier 2 (Popovers, Filter Menus, & Floating Panels):** `#FFFFFF`, `1px solid #E5EAEA`, elevated with `0 4px 16px rgba(36, 28, 36, 0.06), 0 8px 32px rgba(6, 66, 82, 0.04)`.
- **Tier 3 (Modals & Confirmation Drawers):** `#FFFFFF`, enveloped in an ambient backdrop overlay tinted with primary purple at low opacity: `rgba(59, 18, 63, 0.45)` with `backdrop-filter: blur(2px)`. Modal shadow: `0 12px 48px rgba(36, 28, 36, 0.12)`.

## Shapes

The design system standardizes on a measured roundedness architecture:
- **Small Controls (Buttons, Form Inputs, Badges, Tabs):** `8px` (`0.5rem`) for a clean, structural feel.
- **ERP Cards, Panels, & Chart Containers:** `12px` (`0.75rem`), balancing modern software design with enterprise stability.
- **Modals & Slide-out Panels:** `14px` (`0.875rem`) to maintain consistent curvature proportions at large scale.
- **Status Pills & Micro Chips:** Pure pill radius (`9999px`) for quick contextual scanning.

## Components

### Buttons
- **Primary:** Background `#3B123F`, text `#FFFFFF`, border `none`, border-radius `8px`. Hover state shifts to `#542052`. Active state triggers `scale(0.99)`.
- **Secondary (Analytical CTAs):** Background `#005166`, text `#FFFFFF`. Hover shifts to `#064252`.
- **Outline / Neutral:** Background `#FFFFFF`, text `#241C24`, border `1px solid #E5EAEA`. Hover shifts background to `#F7FAFA` with border color darkening to `#CED7D8`.
- **Sizes:** Compact (`36px` height, `12px` horizontal padding), Standard (`42px` height, `16px` horizontal padding).

### Input Fields & Selects
- **Base State:** Background `#FFFFFF`, border `1px solid #E5EAEA`, height `42px`, border-radius `8px`, font size `14px`, text color `#241C24`. Placeholder in `#49636A` (60% opacity).
- **Focus State:** Border color `#005166`, ring `3px rgba(0, 81, 102, 0.12)`.
- **Error State:** Border color `#D32F2F`, ring `3px rgba(211, 47, 47, 0.12)`.

### Cards & Metrics (KPIs)
- **Container:** Background `#FFFFFF`, border `1px solid #E5EAEA`, border-radius `12px`, padding `20px`.
- **Metric Card Anatomy:** Small category caption (`label-md`, `#49636A`), prominent value display (`metric-kpi`, `#241C24`), and bottom status badge showing delta trends (`+4.2% vs last cycle`) wrapped in contextual status pills.

### Data Tables
- **Header:** Background `#F7FAFA`, text `#49636A`, `label-sm`, uppercase, letter-spacing `0.05em`, border-bottom `1px solid #E5EAEA`, height `40px`.
- **Rows:** Alternating transparent and `#FFFFFF`. Hover state smoothly transitions background to `#EEF7F7`. Border-bottom `1px solid #E5EAEA`.
- **Numeric Cells:** Right-aligned, tabular numerical figures (`tnum`).

### Status Badges & Pills
- **Success / Completed:** Background `#EEF7F7`, text `#005166`, border `1px solid rgba(0, 81, 102, 0.15)`.
- **Pending / In Review:** Background `#F6F0F7`, text `#3B123F`, border `1px solid rgba(59, 18, 63, 0.15)`.
- **Critical / Rejected:** Background `#FFF2F2`, text `#B71C1C`, border `1px solid rgba(183, 28, 28, 0.15)`.
- **Neutral / Draft:** Background `#F7FAFA`, text `#49636A`, border `1px solid #E5EAEA`.

### Checkboxes & Radio Buttons
- **Checkbox:** `18px` square, border `1.5px solid #CED7D8`, border-radius `4px`. Checked state uses `#3B123F` background with an inverted white check icon.
- **Radio:** `18px` circle, border `1.5px solid #CED7D8`. Selected state renders `#3B123F` outer ring with an inner concentric dot (`6px`).
